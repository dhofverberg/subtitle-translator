# Sample files

This directory contains small, original synthetic subtitle files for testing
and demonstration purposes. None of the files contain copyrighted material.

## Translation samples

### `openai_smoke_test.srt`

A short English SRT file with four subtitles demonstrating basic translation
features: Unicode emoji, accented characters, a multiline entry, a robot
counting phrase, and an em-dash. Use this file for a quick manual smoke test:

```bash
subtitle-translator translate samples/openai_smoke_test.srt \
  --source-language English --target-language Swedish
```

### `openai_glossary_test.srt`

An extended English SRT file that contains terminology covered by the sample
glossary (`glossary.en-sv.json`). Use this to verify glossary enforcement,
including plural and inflected forms:

```bash
subtitle-translator translate samples/openai_glossary_test.srt \
  --source-language English --target-language Swedish \
  --glossary samples/glossary.en-sv.json
```

## Rolling-context sample

### `context_smoke_test.srt`

An English SRT file where the relationship term "grandmother" is established
early. Use this to verify that rolling context helps maintain consistent
terminology across batches.

### `context_smoke_test.old-translated.srt`

An illustrative Swedish translation of `context_smoke_test.srt`. This file
demonstrates the expected context-guided output (e.g., consistent use of
`mormor` derived from the established "father's mother" relationship). It is
provided as a reference only and is not regenerated by automated tests.

## Consistency-review sample

### `consistency_smoke_test.srt`

An English SRT file designed to trigger a consistency-review finding. It
references "grandmother" in multiple subtitles and introduces a "First Officer"
term covered by the glossary. Use it to verify that the consistency reviewer
identifies potential terminology variations:

```bash
subtitle-translator translate samples/consistency_smoke_test.srt \
  --source-language English --target-language Swedish \
  --glossary samples/glossary.en-sv.json \
  --consistency-report consistency_smoke_test.consistency.md
```

## Glossary

### `glossary.en-sv.json`

A sample English-to-Swedish glossary demonstrating the expected JSON shape:

```json
{
  "source_language": "English",
  "target_language": "Swedish",
  "terms": [
    { "source": "quiet robot", "target": "tystlåten robot" },
    { "source": "Good night",  "target": "God natt" },
    { "source": "First Officer", "target": "sekond" }
  ]
}
```

## Notes

- Generated translated SRT files (`*.translated.srt`) and consistency reports
  (`*.consistency.md`) are excluded from version control via `.gitignore`.
- All subtitle text is original synthetic content — do not replace it with
  copyrighted film or television material.
